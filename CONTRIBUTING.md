# Contributing

Thank you for your interest in Netloom.

Netloom is developed by Seyhan Labs and is dual licensed: the public source is GPL-3.0-or-later,
and Seyhan Labs also distributes it under other terms (for example on the App Store). This only
works while Seyhan Labs holds the rights to all of the code.

For that reason **pull requests can only be merged from contributors who have signed the
Netloom Contributor Licence Agreement (CLA)**, which lets Seyhan Labs distribute your
contribution under the GPL and under other licences, while you keep the copyright of your work.
The CLA is not published yet; until it is, please open an issue instead of a pull request -
bug reports, test files and feature ideas are very welcome.

Please do not copy code from other projects (including KiCad, whose source is GPL) into
Netloom. Reading other programs to understand a file format or a behaviour is fine; the code
has to be your own.
